## 📌 Project Overview
This repository contains a Tableau-based analytical project focused on airline and airport performance across the United States.  
The dashboards explore delays, cancellations, seasonal patterns, operational efficiency, and the root causes of flight disruptions.

The project includes:
- **Two interactive dashboards published on Tableau Public**
- **A PDF file with two screenshots**
- **This README.md**

No local Tableau workbooks are stored in the repository.  
All dashboards are accessible via public links.

---

## 📊 Dashboards

### 1️⃣ Airlines & Airports Performance  
**Tableau Public:** 
https://public.tableau.com/views/AirlinesPerformanceAnalytics/AirlinesAirports?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link

This dashboard provides a high-level overview of flight activity and performance:

- **KPI Panel**
  - Total Flights  
  - Delayed Flights (%)  
  - Cancelled Flights (%)  
  - Monthly trend sparklines  

- **Top N Analysis**
  - Top 10 Outsiders (highest delay rates)
  - Top 10 Best Airlines (lowest delay rates)

- **Geographical Map**
  - Airports by Total Flights across the U.S.

- **Trend Line**
  - Monthly trend of total flights

- **User Filters**
  - Airline  
  - Airport  
  - State  
  - City  
  - Month  
  - Day of Year  
  - Metric Selector  
  - Dimension Selector

### 2️⃣ Airline Performance Overview  
**Tableau Public:** [ADD_LINK_2]

This dashboard provides deeper analytical insights:

- **Best Airlines by Gained Time**  
  Identifies airlines that recover time during flight despite initial delays.

- **Route & Delay Time**  
  Scatter plot with average delay benchmarks.

- **Seasonality Delay Index**  
  Monthly delay index per airline.  
  Values closer to 1 indicate worse seasonal performance.

- **Delay Reason Breakdown**  
  Donut chart showing:
  - Weather  
  - Late Aircraft  
  - Air System  
  - Airline  

- **Cancellation Breakdown**
  - Weather  
  - Airline / Carrier  
  - National Air System  
  - Security / Unknown  

- **User Filters**
  - Airline  
  - Airport  
  - State  
  - City  
  - Month  
  - Day of Year  


## 🚀 How to Access the Dashboards
1. Open the Tableau Public links provided above.  
2. Dashboards are fully interactive and require no local files.  
3. PDF screenshots are available in the `/docs` folder.

---

## 🔍 Key Insights
- Some airlines successfully recover lost time during flight (gained time).
- Seasonal delay patterns vary significantly across carriers.
- Weather is the primary cause of cancellations.
- Air System and Airline factors are the main contributors to delays.
- Airports with the highest traffic show increased operational risks.
